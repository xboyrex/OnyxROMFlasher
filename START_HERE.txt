🔧 USAGE WORKFLOW

  1. Select AOSP ROM ZIP
  2. Tool validates ROM and extracts payload
  3. Connect phone in fastboot mode
  4. Tool flashes 5 boot partitions
  5. Phone reboots to recovery automatically
  6. Select "Apply from ADB" in recovery
  7. Tool transfers ROM via sideload
  8. Device boots with new ROM
  (Total time: 2-5 minutes)

⚠️  IMPORTANT NOTES

  • Backup your data before flashing
  • Bootloader MUST be unlocked
  • Keep USB cable connected throughout
  • Don't interrupt during flashing
  • First boot takes 5-10 minutes
  • This tool only works with POCO F7 (onyx)
